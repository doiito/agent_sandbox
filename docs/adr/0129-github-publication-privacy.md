# ADR-0129：GitHub 交付的隐私门禁

状态：Accepted；日期：2026-11-17；需求 REL-04、QA-01、QA-05。

用户明确要求：所有上传 GitHub 的代码、文档、安装包和附件都不能包含远程运维账号、密码、服务地址、本机工作目录、业务数据或其他隐私。此约束优先于“先发布”。本轮旧草稿与新建分支/标签已撤下，旧安装包没有上传；删除引用不能被描述为已清除托管方的孤立对象或缓存。

公开源码使用单独生成的干净历史和明确允许的产品源码/文档清单。原始验证日志、主机报告、SSH 控制程序、本地业务文件、凭据和私有扫描策略仅在项目私有验证目录保留。公开证明仅保留架构、用例计数、匿名性能样本、版本及制品摘要，不公开运维身份、主机拓扑、原始请求或本机路径。

Rust 编译通过 `--remap-path-prefix` 使用稳定虚拟源码路径，C 编译使用文件/调试路径映射；编译器原始记录私有保留，公开来源记录使用规范化路径。许可证原文保持，通过固定 gzip/tar 时间、所有者和归档路径生成可重复的归档，不能为脱敏修改许可证原文。真实库及运行镜像继续存项目目录。

新增发布隐私扫描：本地私有策略提供不允许公开的实际值；可选秘密经继承文件描述符输入，不写命令行、文件或扫描结果。扫描覆盖 Git 的显式来源清单、包内普通文件、二进制和嵌套许可证归档，拒绝私钥、链接/特殊文件及意外路径。正式构建要求隐私策略，上传动作还须核验最终全部附件的摘要和隐私验收绑定。普通系统路径、协议 URL、合成测试值和第三方公开许可证不等同于操作者隐私。

编译路径变化已经涉及 guest 载荷，必须生成新候选并重新绑定功能与性能验收。原候选的千次成绩和失败/成功记录保持，不将旧完整包的 SHA 改名绑定到新包；不降低 5/9/15 ms 门槛，不重复采样原候选凑绿。K8s、ARM KVM 和指定过期域名 TLS 仍按既有用户范围暂缓。

自评审：隐私策略和扫描报告都不得回显秘密；单独安全的文本不代表完整 tar 安全，最终上传附件也必须扫描。源码快照不能携带未脱敏祖先提交。镜像需要同时检查已分配内容和原始磁盘剩余区域；发现残留先修复再生成签名与摘要。上传工具不得通过报告生成后修改附件来绕过门禁。
