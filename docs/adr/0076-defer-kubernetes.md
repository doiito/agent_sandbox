# ADR-0076：本轮暂缓 Kubernetes 实现

状态：Accepted；日期：2026-11-06；需求 OPS-02；依据：用户明确要求“K8s相关先不用实现”。

本轮交付继续使用 x64/aarch64 Linux 自包含离线包与 systemd 部署。Kubernetes DaemonSet、调度对账、相关控制器与部署门禁暂缓，待用户重新安排后实施。

该决定仅适用于 K8s。OPS-02 中 OCI 签名模板分发与离线验证仍保留，其他功能、VM pool、双架构功能验收和原有性能目标不因本决定关闭。

自评审：暂缓项须与已完成功能区分，不能把本决定作为 OCI 分发已完成的证明，也不新增 K8s 对运行或安装的依赖。本次为交付范围记录，无产品代码变更；检查文档链接和需求矩阵即可，不重复 CI 或 KVM 回归。
