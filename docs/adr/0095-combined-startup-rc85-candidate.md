# ADR-0095：合并启动优化的 rc85 候选验收

状态：Accepted（完整功能候选，正式性能仍开放）；日期：2026-11-11；需求 LIFE-04、PERF-03、QA-01/02/03、REL-04、BUILD-01。

## 决策依据与范围

[单次持久提交对照](../../PUBLIC-QUALIFICATION.md#private-evidence)中，两后端领取启动 p50 分别降低约 16%/18%；[冷启动诊断](../../PUBLIC-QUALIFICATION.md#private-evidence)中，关闭无用途键鼠探测后的正常日志单 VM 就绪观察由 699.348 降至 327.133 ms。两项优化各已完成设计、自评审与定向验证，但当前完整功能基线仍是 rc83，两个诊断结果都不能替代合并候选验收。

冻结 `2026.11.11-rc85`：包含 ADR-0091 的单次最终持久归属和 ADR-0094 的固定无键鼠参数，保留 rc83 的静态 guest、独立 System supervisor、PID1/executor mimalloc secure=4、有界 helper 读取及全部现有 SDK/MCP/gRPC/代码/推理/代理/端口功能。没有新 guest 构建、协议变更、K8s 或增强安全前置。当前 warm 目标为 5/8/10 ms，cold 为 400/600/1000 ms。

## 执行策略

先完成[自评审](../../PUBLIC-QUALIFICATION.md#private-evidence)。绑定 rc83 来源清单与当前源码/实际资产摘要，保存变更源码归档，使用现有项目验证环境在宿主执行一次规范完整 CI；受限环境的 socket 拒绝已由两轮定向证据确认，无需重复该环境失败。输入在 CI 和打包前后必须保持一致。

CI 成功后构建并验签同版本 x64/aarch64 完整离线包及静态安装器，校验全部模板签名、SBOM、ABI、许可证和目标 ISA。完成 x64 非 root 安装/真实 API，ARM 无网卡 QEMU 原 58 组，指定服务器相同 x64 包的原 15 套/516 个用例与 44 个 gRPC 用例。后两项可分别在本地和服务器推进，但同一服务器的夹具继续共用验证锁。原始任务 ID 和 InvocationID 不变，未知执行结果不重放。

同候选的正式启动验收使用正常 mTLS API、正常日志/健康检查和原计时起止，每必要后端/路径至少 1000 次成功正式样本；生产宿主未就绪则保留为诊断，不能登记为通过。先审查宿主实际状态和生产基线再处理部署条件，不由测量工具修改全局 swap/CPU 策略。不通过重命名旧候选或降低样本/一般安全要求开放发布。

冻结后若失败，先保留原失败并做定点修正；根据变化范围决定重跑受影响组，只有生产输入变化或完整 CI 未完成才补相应完整候选检查。已证明无引用的重复安装/打包副本及时清理，实际依赖和证据保存在项目中。

资源、同任务性能、长稳、原需求矩阵和正式发行仍独立开放。该候选通过也只推进已验证的功能/性能基线，不代表原总目标全部完成。

[rc85 完整功能验收](../../PUBLIC-QUALIFICATION.md#private-evidence)已通过。SDK 夹具固定未就绪假设的原失败保留，按 ADR-0097 显式检查就绪预期后用新 ID 补齐受影响组，同一发行包未变。后续启动采样按 ADR-0096 进行，尚未登记正式性能通过。
