# Release 2026.11.17 qualification

Linux x64 and aarch64 packages support offline installation and execution. Dependencies are bundled. Offline source rebuilding is outside this release scope.

The release passed 21 actual KVM functional fixtures and 65 ARM QEMU test groups without a network device. Four startup routes each contain 1,000 formal samples and five warmups. All 4,020 jobs and VMs were unique.

| Route | p50 / p95 / p99 (ms) |
| --- | --- |
| linuxwarm | 3.057 / 6.377 / 12.531 |
| linuxcold | 270.853 / 340.421 / 372.063 |
| osvwarm | 2.396 / 3.419 / 3.928 |
| osvcold | 61.153 / 78.905 / 89.152 |

Warm startup limits are p50 ≤ 5 ms, p95 ≤ 9 ms and p99 ≤ 15 ms. Cold startup limits are 400/600/1,000 ms. Startup excludes full HTTP execution and pool availability waiting. Independent refill observations cover 128 consumers; those durations conservatively include foreground execution and observation, rather than timing worker function entry.

Pool management programs and SDKs retain the previous qualified bytes. Linux guest images were rebuilt to remove private compiler paths and generated bytecode, then passed fresh guest functional validation. There is no claim that the Linux images are byte-identical or that mimalloc improves overall workload performance.

This release uses baseline security. ARM KVM deployment, Kubernetes and custom-domain TLS acceptance are deferred. Signed artifacts currently expire at 2026-12-07T00:00:00Z.
